## ✨ Возможности

- **100% офлайн** — никаких API-ключей и интернета после загрузки моделей
- **Silero VAD** — умное определение активности голоса, автоматически пропускает тишину
- **Поддержка GPU / CPU** — ускорение CUDA для видеокарт NVIDIA, а также работа на процессоре
- **Пакетная обработка** — закиньте целую папку с аудиофайлами, и программа обработает их все
- **Экспорт в SRT** — опциональное создание файлов субтитров с таймкодами вместе с обычным текстом
- **Двуязычный интерфейс** — переключение между русским и английским в один клик
- **3 профиля** — Быстрый · Точный · Шумная запись (покрывают большинство задач)
- **Оценка WER / CER** — встроенный скрипт для измерения точности транскрибации

## 🖥️ Системные требования

| Компонент | Минимум |
|-----------|---------|
| ОС | Windows 10 / 11 |
| Python | 3.10 или новее |
| ОЗУ | 8 ГБ |
| Видеокарта | Видеокарта NVIDIA с поддержкой CUDA 12.4 *(рекомендуется)* |
| Видеопамять| 4 ГБ для `whisper-medium`, 10+ ГБ для `large` |
| Место | ~3 ГБ на каждую модель Whisper |

> **Режим работы только на процессоре (CPU-only) поддерживается**, но работает значительно медленнее — ожидайте увеличения времени обработки в 5–10 раз.

## ⚡ Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/Anim-2022/Whisper.git
cd Whisper
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
.venv\Scripts\activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

> PyTorch с CUDA 12.4 скачивается автоматически по ссылке, указанной в `requirements.txt`.

### 4. Загрузка модели Whisper

Скачайте модель с [Hugging Face — openai/whisper-medium](https://huggingface.co/openai/whisper-medium) и поместите её в:

```
models/
└── models--openai--whisper-medium/
    ├── refs/
    └── snapshots/
        └── <hash>/          ← файлы модели сюда
```

Или при первом запуске программа покажет ожидаемый путь в разделе **Модель**.

### 5. (Опционально) Загрузка Silero VAD

```bash
git clone https://github.com/snakers4/silero-vad.git models/silero-vad
```

VAD значительно улучшает качество сегментации. Без него программа использует простую нарезку скользящим окном.

### 6. Запуск

```bash
Start_Whisper.bat        # двойной клик или запуск в терминале
# или
python start_gui.py
```

## 📁 Структура проекта

```
Whisper/
├── whisper_core.py          # Ядро: VAD, сегментация, батчинг, обработка нехватки памяти (OOM)
├── whisper_gui.py           # GUI на CustomTkinter (EN/RU интерфейс)
├── start_gui.py             # Точка входа
├── evaluate_transcriptions.py  # Инструмент оценки WER/CER
├── Start_Whisper.bat        # Launcher для Windows
├── requirements.txt         # Зависимости Python
├── models/                  # ← Сюда класть модели Whisper + Silero VAD (не коммитятся)
├── audio/                   # ← Папка для входящих файлов по умолчанию (не коммитится)
└── audio_to_text/           # ← Папка для результатов по умолчанию (не коммитится)
```

## 🎛️ Профили

| Профиль | Для чего подходит |
|--------|----------|
| **Быстрый** *(по умолчанию)* | Ежедневная офлайн-транскрибация, баланс скорости и качества |
| **Точный** | Когда точность слов важнее скорости; использует beam search |
| **Шумная запись** | Проблемные записи с фоновым шумом или разорванной речью |

## ⚙️ Расширенные настройки

Все расширенные параметры доступны на вкладке **Расширенные**:

| Параметр | Описание |
|-----------|-------------|
| Устройство | `cuda` / `cpu` / `mps` для вычислений |
| Точность | `float16` (GPU, быстрее) или `float32` (CPU, безопаснее) |
| Размер батча | Чанки, обрабатываемые параллельно. Уменьшите, если не хватает памяти |
| Порог VAD | Чем выше, тем агрессивнее вырезается тишина (и случайные звуки) |
| Профиль декодинга | `balanced` или `quality` (beam search, медленнее) |
| Целевой dB | Уровень нормализации громкости перед транскрибацией |
| Склейка паузы | Макс. пауза (сек) для объединения соседних сегментов VAD |
| Мин. тишина | Мин. тишина (мс) для того, чтобы VAD разделил сегмент |
| Длина чанка (сек)| Резервная длина чанка, если VAD отключен |
| Перекрытие (сек)| Перекрытие чанков для предотвращения обрезания слов на границах |
| Макс. новых токенов| Лимит токенов на чанк. Меньше — меньше галлюцинаций |

## 📊 Оценка качества транскрибации

Сравните полученный текст с эталонным (reference):

```bash
python evaluate_transcriptions.py \
    --pred-dir audio_to_text/ \
    --ref-dir  path/to/reference_texts/
```

Вывод:

```
File                                     WER      CER
------------------------------------------------------------
interview_01.txt                      5.200%   2.100%
lecture_02.txt                        8.700%   3.400%
------------------------------------------------------------
Average                               6.950%   2.750%
```

> Эталонные `.txt` файлы должны иметь **такие же имена**, как и файлы с предсказаниями.
